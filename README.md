# Python 100 Projects Challenge 🐍

A collection of **100 Python projects** built to improve my programming skills, strengthen problem-solving abilities, and gain practical development experience.

## 🎯 Objectives
- Practice Python through hands-on projects.
- Improve logical thinking and problem-solving.
- Explore Python libraries and frameworks.
- Build a portfolio of practical projects.

## 📂 Projects

| No. | Project Name | Description |
|---:|---|---|
| 1 | Band Name Generator | A simple Python project that generates a potential band name by combining the name of the city where the user grew up with their pet's name. |
| 2 | Tip Calculator | A simple Python program that calculates how much each person should pay when splitting a bill, including the selected tip percentage. |
| 3 | Treasure Island | Treasure Island is a text-based adventure game built with Python. The player makes choices at different stages of the game to find hidden treasure. Every decision leads to a different outcome, and only the correct choices lead to victory. |
| 4 | Rock Paper Scissors | A simple command-line Rock Paper Scissors game built with Python. The player chooses rock, paper, or scissors, and the computer randomly selects its move. The game compares both choices and determines the winner. |
| 5 | Password Generator | Password Generator is a Python program that creates random passwords based on the number of letters, numbers, and symbols specified by the user. It shuffles the characters to generate a password with a randomized character order. |
| 6 | Hangman Game | Hangman is a text-based word-guessing game built with Python. The player must guess a randomly selected word one letter at a time. Each incorrect guess costs one life, and the player has six lives to guess the word correctly. |
| 7 | Caesar Cipher | Caesar Cipher is a simple Python program that encrypts and decrypts messages by shifting each letter of the alphabet by a specified number of positions. Users can choose between encoding and decoding and repeat the process as many times as they want. |
| 8 | Blind Auction | The Blind Auction Program is a command-line application built with Python that allows multiple bidders to place bids privately. After all bidders have entered their bids, the program identifies and announces the highest bidder. |
| 9 | Calculator | A command-line calculator built with Python that performs basic arithmetic operations, including addition, subtraction, multiplication, and division. It allows users to continue calculations using the previous result or start a new calculation. |
| 10 | Blackjack Game | A command-line Blackjack game built with Python. The player competes against the computer by drawing cards and trying to achieve a score as close to 21 as possible without exceeding it. |
| 11 | Number Guessing Game | The Number Guessing Game is a simple Python command-line game in which the computer randomly selects a number between 1 and 100. The player must guess the number within a limited number of attempts. |
| 12 | Higher or Lower Game | The Higher or Lower Game is a Python command-line game in which players compare two Indian personalities or entities and guess who has more followers. |
