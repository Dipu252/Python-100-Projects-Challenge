# 🔐 Password Generator

## 📌 Description
Password Generator is a Python program that creates random passwords based on the number of letters, numbers, and symbols specified by the user. It shuffles the characters to generate a password with a randomized character order.

## ✨ Features
- Customize the number of letters in the password.
- Specify the number of numbers and symbols.
- Includes uppercase and lowercase letters.
- Randomly shuffles characters to mix their order.
- Simple and interactive command-line interface.

## 🛠️ Technologies Used
- Python 3
- `random` module
- Lists and loops
- `random.choice()` and `random.shuffle()`
- String concatenation

## 🚀 How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```

## 💻 Example Output

```text
Welcome to the Password Generator!
How many letters would you like in your password?
6
How many symbols would you like?
2
How many numbers would you like?
3

Password: aB7!k2#Lm9
```

*The generated password will vary each time you run the program.*

## 📚 Learning Outcomes
- Working with lists and loops.
- Generating random characters using `random.choice()`.
- Shuffling list elements using `random.shuffle()`.
- Taking and processing user input.
- Combining characters to create a string.
