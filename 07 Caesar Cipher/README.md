# 🔐 Caesar Cipher

## 📌 Description
Caesar Cipher is a simple Python program that encrypts and decrypts messages by shifting each letter of the alphabet by a specified number of positions. Users can choose between encoding and decoding and repeat the process as many times as they want.

## ✨ Features
- Encrypt messages using a shift number.
- Decrypt previously encrypted messages.
- Supports lowercase English letters.
- Preserves spaces, numbers, and special characters.
- Allows users to restart the program.
- Displays a logo when the program starts.

## 🛠️ Technologies Used
- Python 3
- Lists and loops
- Functions
- Conditional statements
- String manipulation
- Modulo operator (`%`)
- Custom module imports

## 🚀 How to Run

1. Install Python 3.
2. Make sure `main.py` and `art.py` are in the same folder.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎯 How to Use
1. Choose `encode` to encrypt or `decode` to decrypt.
2. Enter the message you want to process.
3. Enter the shift number.
4. View the resulting message.
5. Choose `yes` to continue or `no` to exit.

- Using loops and conditional statements.
- Manipulating strings and lists.
- Applying the modulo operator for alphabet wrapping.
- Implementing encryption and decryption logic.
- Using a loop to repeat a program.

## ⚠️ Limitations
- The program converts messages to lowercase.
- It supports only the English alphabet for shifting.
- It is an educational project and is not suitable for securing sensitive information.
