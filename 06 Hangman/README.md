# 🎮 Hangman Game

## 📌 Description
Hangman is a text-based word-guessing game built with Python. The player must guess a randomly selected word one letter at a time. Each incorrect guess costs one life, and the player has six lives to guess the word correctly.

## ✨ Features
- Random word selection from a predefined word list.
- Interactive letter-guessing gameplay.
- Six lives to guess the hidden word.
- Displays correctly guessed letters.
- Tracks remaining lives.
- ASCII art logo and hangman stages.
- Win and lose conditions.

## 🛠️ Technologies Used
- Python 3
- `random` module
- Lists and loops
- Conditional statements
- String manipulation
- Module imports

## 🚀 How to Run

1. Install Python 3.
2. Make sure `main.py`, `hangman_words.py`, and `hangman_art.py` are in the same folder.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎯 How to Play

1. Run the game.
2. Guess a letter when prompted.
3. Correct guesses reveal letters in the hidden word.
4. Incorrect guesses reduce your remaining lives.
5. Guess the complete word before running out of lives to win!
