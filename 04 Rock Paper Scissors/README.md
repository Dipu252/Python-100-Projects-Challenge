# ✊ Rock Paper Scissors

## 📌 Description
A simple command-line Rock Paper Scissors game built with Python. The player chooses rock, paper, or scissors, and the computer randomly selects its move. The game compares both choices and determines the winner.

## ✨ Features
- Interactive command-line gameplay.
- Random computer selection.
- ASCII art for rock, paper, and scissors.
- Automatic winner determination.
- Input validation for choices greater than 2.

## 🛠️ Technologies Used
- Python 3
- `random` module
- `input()` and `print()` functions
- Conditional statements (`if`, `elif`, `else`)
- Nested conditional logic

## 🚀 How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```

## 🎮 How to Play

1. Run the program.
2. Enter `0` for Rock, `1` for Paper, or `2` for Scissors.
3. The computer randomly chooses its move.
4. The game displays both choices and announces the result.
