# 🏝️ Treasure Island

## 📌 Description
Treasure Island is a text-based adventure game built with Python. The player makes choices at different stages of the game to find hidden treasure. Every decision leads to a different outcome, and only the correct choices lead to victory.

## ✨ Features
- Interactive text-based gameplay.
- ASCII art introduction.
- Multiple paths and choices.
- Different game-over scenarios.
- A treasure-winning ending.

## 🛠️ Technologies Used
- Python 3
- `print()` function
- `input()` function
- Conditional statements (`if`, `elif`, `else`)
- Nested conditional statements
- Multiline strings

## 🚀 How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```

## 🎮 How to Play
1. Choose **left** or **right** at the crossroads.
2. Choose **wait** or **swim** at the lake.
3. Choose a door: **red**, **yellow**, or **blue**.
4. Make the right choices to find the treasure and win the game!

## 💻 Example Output

```text
Welcome to Treasure Island.
Your mission is to find the treasure.

You're at a crossroad. Where do you want to go?
Type 'left' or 'right'?

You've come to a lake. There is an island in the middle of the lake.
Type 'wait' to wait for a boat. Type 'swim' to swim across.

You arrive at the island unharmed. There is a house with 3 doors.
One red, one yellow, and one blue. Which colour do you choose?

You Win!
```
