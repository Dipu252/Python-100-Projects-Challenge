# Number Guessing Game 🎯

## 📌 About the Project
The **Number Guessing Game** is a simple Python command-line game in which the computer randomly selects a number between 1 and 100. The player must guess the number within a limited number of attempts.

The game offers two difficulty levels: **Easy** and **Hard**.

## 🚀 Features
- Generates a random number between 1 and 100.
- Provides two difficulty levels: Easy and Hard.
- Allows 10 attempts in Easy mode.
- Allows 5 attempts in Hard mode.
- Displays hints such as "Too low" and "Too high".
- Informs the player when they guess the correct number.
- Displays a message when all attempts are used.
- Uses ASCII art for the game logo.

## 🛠️ Technologies Used
- Python
- `random` module
- Custom `art` module

## ▶️ How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python main.py
```

## 🎮 How to Play
1. Start the game.
2. Choose a difficulty level by typing `easy` or `hard`.
3. Enter a number between 1 and 100.
4. Read the hint displayed by the game.
5. Continue guessing until you find the correct number or run out of attempts.

### Difficulty Levels

| Difficulty | Number of Attempts |
|---|---:|
| Easy | 10 |
| Hard | 5 |
