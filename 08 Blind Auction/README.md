# 🔨 Blind Auction Program

## 📌 Description
The Blind Auction Program is a command-line application built with Python that allows multiple bidders to place bids privately. After all bidders have entered their bids, the program identifies and announces the highest bidder.

## ✨ Features
- Accepts multiple bidders' names and bid amounts.
- Stores bids in a Python dictionary.
- Allows additional bidders to participate.
- Clears the screen between bidders to keep bids private.
- Automatically identifies the highest bidder.
- Displays the winner and their bid amount.

## 🛠️ Technologies Used
- Python 3
- Dictionaries
- `input()` and `print()` functions
- `while` loops
- Conditional statements
- `max()` function
- Custom module imports

## 🚀 How to Run

1. Install Python 3.
2. Make sure `main.py` and `art.py` are in the same folder.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎮 How to Use
1. Enter your name.
2. Enter your bid amount.
3. Indicate whether other bidders want to participate.
4. Each additional bidder enters their name and bid.
5. After bidding ends, the program announces the highest bidder.
