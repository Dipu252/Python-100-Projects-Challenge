# 🎸 Band Name Generator

## 📌 Description
A simple Python project that generates a potential band name by combining the name of the city where the user grew up with their pet's name.

## ✨ Features
- Takes the user's city name as input.
- Asks for the user's pet name.
- Combines both inputs to generate a unique band name.
- Displays the suggested band name.

## 🛠️ Technologies Used
- Python 3
- `input()` function
- `print()` function
- String concatenation

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository or download the project.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

```text

What's the name of the city you grew up in?

What's your pet name?

```
