# 💰 Tip Calculator

## 📌 Description
A simple Python program that calculates how much each person should pay when splitting a bill, including the selected tip percentage.

## ✨ Features
- Accepts the total bill amount.
- Allows the user to choose a tip percentage.
- Takes the number of people sharing the bill.
- Calculates the amount each person should pay.
- Displays the final amount rounded to two decimal places.

## 🛠️ Technologies Used
- Python 3
- User input with `input()`
- Type conversion using `float()` and `int()`
- Arithmetic operations
- Formatted strings (f-strings)
- Rounding with `round()`

## 🚀 How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```
