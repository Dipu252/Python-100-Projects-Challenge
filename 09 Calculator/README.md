
# 🧮 Calculator

## 📌 Description
A command-line calculator built with Python that performs basic arithmetic operations, including addition, subtraction, multiplication, and division. It allows users to continue calculations using the previous result or start a new calculation.

## ✨ Features
- Supports addition, subtraction, multiplication, and division.
- Accepts decimal numbers.
- Uses functions to perform calculations.
- Allows continuous calculations using previous results.
- Provides an option to start a new calculation.
- Displays results in a readable format.

## 🛠️ Technologies Used
- Python 3
- Functions
- Dictionaries
- Loops and conditional statements
- User input and formatted strings

## 🚀 How to Run

1. Install Python 3.
2. Make sure `main.py` and `art.py` are in the same folder.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```
