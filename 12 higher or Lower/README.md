# Higher or Lower Game 🇮🇳

## 📌 About the Project
The **Higher or Lower Game** is a Python command-line game in which players compare two Indian personalities or entities and guess who has more followers.

The game displays two options, A and B, with their names, descriptions, and countries. The player must choose the option with the higher follower count. The game continues until the player makes an incorrect guess.

## 🚀 Features
- Compares two randomly selected entries from a dataset.
- Displays the name, description, and country of each entry.
- Asks the player to choose between options A and B.
- Checks the answer using follower counts.
- Increases the score for every correct guess.
- Displays the current score after a correct answer.
- Shows the final score when the player guesses incorrectly.
- Uses ASCII art for the logo and comparison symbol.

## 🛠️ Technologies Used
- Python
- `random` module
- Custom `art` module
- Custom `indian_data` module

## 🎮 How to Play
1. Start the game.
2. Read the details displayed for options A and B.
3. Type `A` or `B` to select who you think has more followers.
4. Earn one point for each correct answer.
5. Continue playing until you make an incorrect guess.
6. Check your final score.
